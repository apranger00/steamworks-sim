Match sounds
============

Put the sound files in this folder. sounds.json says which file plays for each cue
(mp3, wav or ogg). A missing file plays a placeholder tone instead.

  matchStart  2:30, AUTO starts          frc-start-sound.mp3  (cavalry charge)
  autoEnd     AUTO ends (3 s pause)      frc-end.mp3          (buzzer)
  teleopStart TELEOP starts              frc-resume.mp3
  endgame     0:30 left, ropes drop      frc-warning.mp3      (steam whistle)
  matchEnd    0:00                       frc-end.mp3          (buzzer)

Downloads:
  https://www.myinstants.com/media/sounds/frc-start-sound.mp3
  https://www.myinstants.com/media/sounds/frc-end.mp3
  https://www.myinstants.com/media/sounds/frc-warning.mp3

Changes are picked up the next time you press Play (or start the game).
